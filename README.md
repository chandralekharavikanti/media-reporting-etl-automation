# Multi-Source Media Reporting ETL & Automation

Automated media reporting pipeline using Python, SQL, SQLite, and Excel. Consolidates synthetic digital traffic, print circulation, and advertising data into validated reporting tables and an executive dashboard.

**Portfolio demonstration using synthetic media data (not SME company data).**

## Business problem
A publisher receives disconnected digital traffic, print circulation, advertising bookings, and payment exports. This project consolidates four sources, validates records, loads SQLite, and generates daily, weekly, and monthly reporting tables.

## Architecture
Four source CSVs → Python validation and deduplication → SQLite warehouse → SQL reports + data-quality audit.

## Run
Python 3.10+; no third-party packages required.

```bash
python -m src.generate_sample_data
python -m src.pipeline
python -m unittest discover -s tests -v
```

## Definitions
Traffic measures sessions/pageviews; print circulation measures physical copies, not impressions. Booked revenue is not recognized revenue. Payments are simulated and not revenue recognition.

## Reporting
Daily and weekly traffic; monthly circulation and publication performance. All data and findings are synthetic.

## Portfolio scope
Pipeline source, tests, sample data, and report outputs are supplied in the project package.
## Automated Excel executive dashboard

The pipeline now generates a **reproducible Excel workbook** from its reporting CSVs using `openpyxl`. The dashboard includes four formula-driven executive KPIs, monthly sessions and booked-revenue charts, publication comparisons, and formatted detail tables for monthly media, daily traffic, print circulation, and data quality.

### Build locally

```bash
python -m pip install "openpyxl>=3.1,<4"
python -m src.generate_sample_data
python -m src.pipeline
python -m src.build_excel_dashboard
```

Output: `reports/Media_Reporting_Executive_Dashboard.xlsx`.

### Download from GitHub Actions

Open **Actions → Excel Executive Dashboard → latest successful run → Artifacts → media-executive-reporting** to download the Excel workbook and its supporting CSV reports. The workbook is generated by CI rather than maintained as a manually uploaded binary. This means the reporting output can be rebuilt after code or data changes.

All source data is synthetic. Booked revenue is not recognized revenue; print circulation is measured in physical copies, not digital impressions.
